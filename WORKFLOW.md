# Рабочий процесс: Доведение Freelance Autopilot до идеала

Утверждён операторам (Александр). Используется единый цикл 14 шагов из ТЗ `fusion-response`.

## Принципы работы с агентами
- Каждый шаг — свой агент или субагент с изолированным контекстом
- Результат фиксируется в `state/`, `deliverables/`, `memory/YYYY-MM-DD.md`
- Необратимые действия (доставка, счёт, оплата) — только через ручное подтверждение оператора
- Кнопка «Доставить» и Kill Switch обязательны

## Правила работы с агентами (из .opencode)
- Агент читает `.opencode/agents_index.json` — каталог 400+ агентов по категориям
- `pick_agents()` подбирает исполнителей по ключевым словам ТЗ
- Каждый агент работает в рамках роли (`coder` / `longform`) через LM Studio (`http://127.0.0.1:1234`)
- Не передавать секреты в LLM; не выполнять код клиента вне sandbox

## Команда проверки
После любого изменения запускать:
```bash
python -m pytest tests/ -v
python modules/executor.py  # sanity check
python check_releases.py   # проверка релизов (исправить ошибки)
```
